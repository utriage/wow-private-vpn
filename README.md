# WoW Private VPN (World of Warcraft US 専用プライベートVPN)

World of Warcraft (WoW) の北米 (US) サーバーで遊ぶときに、日本からのラグやパケット詰まりを減らす目的で作ったギルド・身内向けのプライベートVPNです。

- **Author**: Gada

---

## 🎯 対象となる人と前提条件（使う前に読んでね）

このVPNは全員に必須というわけではなく、**「回線トラブルで困っている人」** を助けるための迂回路（バイパス）です。

- **現在の自宅回線で極めて安定している人（常に130ms以下で、日によるブレもほぼない）**:  
  👉 **使わないほうがいいです。**  
  直通回線で快適に遊べている場合、VPNを挟むと暗号化や中継のオーバーヘッドで数ms〜10ms程度逆に遅くなることがあります。今の回線のまま遊ぶのが最速です。
- **「前は普通に遊べていたのに、最近はいつ起動しても200ms / 300ms / 400ms以上になってゲームにならない」という人**:  
  👉 **まさにこのVPNの主要対象です。**  
  プロバイダの国際ルーティング改悪や夜間のパケット詰まりを回避し、AWSの専用光ファイバーへパケットを逃がすことで、安定したプレイ環境に戻せます。

### 📍 東京からの物理距離と ping の目安
パケットは一度 **東京にあるゲートウェイ** を経由してからアメリカ（オレゴン）へ向かうため、東京から物理的に離れている地域ほど国内移動の遅延が上乗せされます。だいたいの目安は以下の通りです：

| お住まいの地域 | 実測 ping の目安 | 状態 |
| :--- | :--- | :--- |
| **関東近郊** | **約 130〜135 ms** | 東京GWまで 2〜5ms。最も理論値に近いです |
| **関西・中部** | **約 140〜145 ms** | 国内移動で +8〜12ms ほど乗ります |
| **九州・東北・北海道** | **約 145〜155 ms** | 国内移動で +15〜22ms ほど乗ります |
| **台湾** | **約 155〜165 ms** | 日台海底ケーブル経由（約30ms）。通常回線より大幅に安定します |

※ どこにお住まいの場合でも、「数百msに急激に跳ね上がったり、パケロスで操作を受け付けなくなる」といった症状を排除し、**パケットロス 0% で安定させること** を主眼に置いています。

## 🔒 セキュリティとプライバシーについて

個人が運用しているVPNに接続するとなると、「PCの中身を覗かれないか」「危ない通信に巻き込まれないか」と不安になる人もいると思います。身内で使うものだからこそ、セキュリティにはかなり気を使って設計しています。

- **メンバー同士の通信は完全遮断**: サーバー側でクライアント同士の通信を遮断（Client Isolation）しているため、同じVPNに繋いでいる他のメンバーからあなたのPCや共有フォルダが見えることはありません。
- **ゲーム通信以外は一切通らない**: 通信を通す宛先を Blizzard のゲームサーバー帯域だけに絞っています。普段のブラウザ閲覧、YouTube、Discordの通話などはご自宅のネット回線をそのまま使うため、何を閲覧しているかを管理者が覗き見ることは物理的にできません。
- **ポートは原則閉鎖**: 外部から攻撃を受ける隙間（アタックサーフェス）を減らすため、サーバーの管理用ポート（SSHなど）は常時閉鎖しており、WireGuardの暗号化通信だけを受け付けます。
- **秘密鍵は手元のみ**: 接続に必要な秘密鍵はあなたのPC内でのみ使われ、Gitリポジトリやサーバー上には残りません。

> 💡 **自分で安全性を判断するのが難しい場合**  
> ChatGPT、Claude、Gemini などの普段使っているAIに、このリポジトリのURLや公開コードをそのまま読ませてみてください。「これってセキュリティ的に危ないことしてない？ 使っても大丈夫そう？」と聞いてみれば、客観的にチェックしてくれるはずです。

詳細な技術仕様については [SECURITY.md](SECURITY.md) にもまとめてあります。

## 🚀 使い方

設定自体はとても簡単で、1分くらいで終わります。

### 1. Gada に声をかける
まずは Discord 等で Gada に「VPN使ってみたい」と声をかけてください。  
あなた専用の接続設定ファイル（`wow-<名前>.conf`）を発行して個人DMでお渡しします。

### 2. 「WireGuard」をインストールする
接続には **WireGuard** という無料の公式アプリを使います。

> **WireGuardとは？**  
> 近年登場したオープンソースの新しいVPNプロトコルです。Linuxカーネル本体にも正式採用されており、従来のVPN（OpenVPNなど）に比べてプログラムのコード量が非常に少なく、動作が軽快でセキュリティ監査もしっかり行われています。怪しげな常駐ソフトが入る心配もありません。

- [WireGuard 公式ダウンロードページ (Windows / Mac)](https://www.wireguard.com/install/) からインストーラーをダウンロードして入れます。

### 3. 設定ファイルを読み込んで「有効化」
1. Gada からDMで届いた `wow-<名前>.conf` をPCに保存します。
2. WireGuard アプリを開き、そのファイルをウィンドウ内にドラッグ＆ドロップします。
3. 一覧に追加された設定を選んで **「有効化」** を押せば接続完了です。
4. あとはいつも通り Battle.net から WoW を起動して遊んでください。

## ❓ よくある質問 (FAQ)

### Q. ゲームをしていない時もオンのままで大丈夫？
**A. 大丈夫です。**  
WoW のゲームサーバー宛て以外の通信（Webサイト、動画、Discord など）はそもそもVPNを通りません。つけっぱなしにしていても普段のPC利用に影響はないです。

### Q. Discord の通話が途切れたり、YouTube が止まったりしない？
**A. 影響ありません。**  
ゲームの通信だけをピンポイントで中継する「スプリットトンネル」という設定にしています。動画やDiscordは普段のご自宅回線のまま直通するため、画質が落ちたり遅延が増えたりはしません。

### Q. アカウントが BAN されたりしない？
**A. 絶対に安全とは言い切れませんが、リスクはかなり低いと考えています。**  
Blizzard の利用規約上、回線の遅延改善を目的とした VPN 利用自体は禁止されていません（ExitLag や Mudfish 等と同じ扱いです）。  
また、市販の共有VPNサービスと違って「不特定多数のユーザーやチーターと同じIPを使い回す」ことがなく、身内専用の固定IPを使っているため、不正利用の巻き添えでアカウントが一時凍結されるようなトラブルも起きにくい構成にしています。ただ、規約の解釈や運用方針はBlizzard側にあるため、最終的には自己判断・自己責任でのご利用をお願いします。

### Q. 他の人に自分の PC の中身を見られたりしない？
**A. 見られません。**  
前述の通り、サーバー側でメンバー同士の通信を遮断（Client Isolation）する設定を入れているため、仲間同士であってもお互いのPCにアクセスすることはできません。

## 🛠️ 仕組みとメリット

日本からアメリカのゲームサーバーへ繋ぐ場合、一般のプロバイダ回線だと太平洋を渡る海底ケーブルの混雑によってパケット詰まりや急なラグが発生しやすくなります。

このVPNでは、Amazon Web Services (AWS) の専用バックボーン回線を経由してパケットを運びます。

```text
[あなたのPC] 
   │ (WoWのパケットだけ)
   ▼
[AWS 東京 Gateway]
   │ (AWSの専用高速光ファイバー)
   ▼
[AWS オレゴン Gateway]
   │ (US西海岸から直接脱出)
   ▼
[Blizzard US サーバー] ── だいたい 130〜135ms くらいで安定
```

Discord やブラウザなどの通常通信はローカル回線のまま直通させつつ、ゲーム通信だけをこのバイパスに乗せることで、低遅延と安定性を両立しています。
